# Nuur Hassan Portfolio

A clean portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive landing page
- Dark/light theme toggle
- Mobile navigation menu
- Service, portfolio, and contact sections

## Run locally
1. Open `index.html` in a browser, or
2. Serve the project with a local static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
This project is ready to be pushed to GitHub and deployed as a static site on services such as GitHub Pages or Netlify.
